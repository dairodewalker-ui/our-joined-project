Introduction to Web Development

Web development is the process of creating websites and web applications that can be accessed through the internet.

HTML provides the structure of a website, while CSS controls its appearance and layout.

Understanding HTML

What is HTML?

HTML stands for HyperText Markup Language. It is used to structure content on web pages.

Basic HTML Elements

  • Headings
  • Paragraphs
  • Images
  • Links
  • Lists

Example of HTML Code

<h1>Hello World</h1>
<p>Welcome to my website.</p>

Understanding CSS

What is CSS?

CSS stands for Cascading Style Sheets. It is used to style and arrange HTML elements.

CSS Properties

  • Color
  • Background color
  • Font size
  • Margin
  • Padding
  • Border

Example of CSS Code

body {
    background-color: lightblue;
    font-family: Arial;
}

Web Development Glossary

HTML
A language used to structure web pages.
CSS
A language used to style web pages.
Browser
A program used to access websites.
Tag
A markup instruction used in HTML.
